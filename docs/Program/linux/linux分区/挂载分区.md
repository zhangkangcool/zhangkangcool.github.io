# linux挂载分区

### 

如果需要使用该备份分区，可以：



1. 手动挂载（临时访问）：

   ```bash
   sudo mkdir -p /mnt/backup  # 创建挂载点
   sudo mount /dev/sda4 /mnt/backup  # 挂载分区
   ls /mnt/backup  # 查看备份内容
   ```

   

2. 设置开机自动挂载（长期使用）：
   编辑 `/etc/fstab` 文件，添加以下行（需替换为实际 UUID）：

   ```shell
   UUID=abc8a4d8-816f-4fe3-9ee6-e6321b7523c7 /mnt/backup ext4 defaults 0 2
   ```

   保存后执行 `sudo mount -a` 使配置生效。



综上，结合标签和文件系统信息，可以确定 `/dev/sda4` 是麒麟系统的备份分区。
