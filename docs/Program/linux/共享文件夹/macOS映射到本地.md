## Ubuntu Samba 共享挂载 macOS 完整教程

### 1. 图形挂载（Finder），临时挂载一次

1. 打开访达 (Finder)，顶部菜单：**前往 → 连接服务器**
2. 地址输入：

```Plain
smb://192.168.1.100/Ubuntu_Share  # Ubuntu_Share是服务器上使用的名字
```

1. 连接身份选择「注册用户」，填写：
   1. 名称：Ubuntu 用户名（如 ubuntu）
   2. 密码：刚才`smbpasswd`设置的密码
2. 选择挂载，侧边栏位置出现共享磁盘。





### 2. 开机自动挂载

步骤 1：打开「系统设置 → 通用 → 登录项」点下方 +，选择刚才挂载好的 myshare，添加到开机启动。或者直接在设置中搜索`登陆项`。
