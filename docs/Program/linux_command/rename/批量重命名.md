

# 批量重命名





### 方法一：使用`rename`命令（Perl 版本）

如果你的系统安装了 Perl 版的`rename`（大多数 Linux 发行版默认安装），可以直接执行：

```bash
rename 's/dump/input/' tempSrc_dump_index-*.ll
```

- `rename`命令使用 Perl 正则表达式替换文件名

- `s/dump/input/`将所有文件名中的`dump`替换为`input`

- `tempSrc_dump_index-*.ll`指定匹配所有源文件

  

### 方法二：使用 Bash 脚本（兼容所有 Linux 系统）

如果没有 Perl 版`rename`，可以使用以下 Bash 脚本：

```bash
#!/bin/bash
for file in tempSrc_dump_index-*.ll; do
    new_name="${file/dump/input}"
    mv -- "$file" "$new_name"
done
```

**使用步骤**：

1. 将上述代码保存为`rename_ll.sh`
2. 赋予执行权限：`chmod +x rename_ll.sh`
3. 执行脚本：`./rename_ll.sh`
