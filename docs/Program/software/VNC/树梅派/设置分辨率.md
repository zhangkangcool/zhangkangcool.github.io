# 树梅派设置分辨率



### 通过树莓派配置工具设置（可用）

1. 在树莓派的终端中输入命令`sudo raspi - config`。
2. 选择 “Display Options”，按回车键。
3. 选择 “VNC Resolution”，按回车键。
4. 根据自身需求选择分辨率，然后按回车键。
5. 选择 “Finish”，并根据提示选择重启树莓派，使分辨率设置生效。

### 修改 VNC 服务器配置文件设置

1. 在树莓派的终端中，使用命令`sudo nano /etc/vnc/config.d/vncserver - x11`，打开 VNC 服务器的配置文件。
2. 在文件中添加或修改`geometry`参数来设置分辨率，例如`geometry = 1280x800`，表示将分辨率设置为 1280x800。
3. 保存并退出编辑器，可通过按`Ctrl+O`保存，`Ctrl+X`退出。
4. 重启 VNC 服务，输入命令`sudo systemctl restart vncserver - x11 - serviced`，使更改生效。

### 通过 xstartup 文件设置

1. 在树莓派的终端中，输入命令`sudo nano /etc/vnc/xstartup`，打开`xstartup`文件。
2. 将 “`XTERM_COMMAND=`” 的值修改为`"xterm - geometry 1366x768+10+10 - ls"`，其中`1366x768`为设置的分辨率，可根据需求进行修改。
3. 按`Ctrl+O`，回车，`Ctrl+X`保存并退出。
