# 树梅派设置全屏



### 核心步骤：设置 VNC Viewer 的缩放模式

1. **连接树莓派**：先用 VNC Viewer 连接上你的树莓派。

2. 打开全屏模式

   ：

   - 在菜单栏选择 `View` -> `Enter Full Screen`。
   - 或者使用快捷键 `Command + U`。

3. 设置缩放选项

   ：

   - 再次点击菜单栏的 `View`。
   - 在 `Scaling`（缩放）选项中，选择 **`Scale to fit`**。

**这样设置后，效果是：**

树莓派的 1920x1080 桌面会被自动拉伸，正好填满你整个 Mac 的屏幕。此时，你在树莓派的浏览器里按 `F11` 键，它就会在这个 “虚拟的” 1920x1080 屏幕里全屏，看起来就和在你 Mac 上全屏一样了。
