

# 树梅派安装VNC



在树莓派上安装`realvnc-vnc-server`后，可以通过以下步骤开启并配置服务：

### 1. 启用 VNC 服务（首次配置）

打开终端，输入以下命令进入树莓派配置界面：

```bash
sudo raspi-config
```

在配置菜单中按以下路径操作：

- 选择 **Interfacing Options**（接口选项）→ **VNC** → 选择 **Yes** 启用 VNC 服务
- 按提示完成设置后，选择 **Finish** 退出配置界面，系统会自动重启 VNC 服务

在`raspi-config`开启后，其实就已经安装了`realvnc-vnc-server`。

### 2. 手动启动 / 停止 / 重启 VNC 服务

如果需要手动控制服务状态，可以使用以下命令：

- 启动 VNC 服务：

  ```bash
  sudo systemctl start vncserver-x11-serviced
  ```

  

- 停止 VNC 服务：

  ```bash
  sudo systemctl stop vncserver-x11-serviced
  ```

  

- 重启 VNC 服务（配置变更后常用）：

  ```bash
  sudo systemctl restart vncserver-x11-serviced
  ```


以下命令显示实时的连接日志：

```shell
journalctl -u vncserver-x11-serviced -f
```





### 3. 设置开机自启动（推荐）

确保 VNC 服务在树莓派重启后自动运行：

```bash
sudo systemctl enable vncserver-x11-serviced
```

如果需要关闭自启动：

```bash
sudo systemctl disable vncserver-x11-serviced
```

### 4. 验证服务状态

检查 VNC 服务是否正常运行：

```bash
sudo systemctl status vncserver-x11-serviced
```

如果服务正常启动，会显示 `active (running)` 状态。

完成以上步骤后，就可以在 macOS 的 RealVNC Viewer 中输入树莓派的 IP 地址（如`192.168.1.100`）进行连接，无需额外指定端口（默认使用 5900 端口）。







```
192.168.31.185:5900
```
