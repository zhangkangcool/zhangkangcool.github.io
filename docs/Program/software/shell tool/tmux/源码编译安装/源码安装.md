# 源码安装


如果可以联网的话，使用`sudo apt-get install tmux`进行安装

下面说的是无法联网时，使用源码编译安装

https://zhuanlan.zhihu.com/p/155662601



### 1. github上下载源代码

```asm
wget https://github.com/tmux/tmux/releases/download/3.5a/tmux-3.5a.tar.gz 
wget https://github.com/libevent/libevent/releases/download/release-2.1.12-stable/libevent-2.1.12-stable.tar.gz
```



### 2. 解压安装

#### 2.1 tmux编译

先直接安装tmux，如果报错在安装libevent

```asm
tar -zxvf tmux-3.5a.tar.gz
cd tmux-3.5a
mkdir build
cd build
../configure  # --prefix=/home/ken/s
make -j
sudo make install  # 无sudo权限则指令  ../configure --prefix=$
```





#### 2.2 libevent编译

报错则编译`libevent`

```shell
cd libevent-2.1.12-stable
mkdir build
cd build
../configure  
make -j
sudo make install  # 无sudo权限则指令  ../configure --prefix=$
```





### 2.3 bison编译

`yacc`报错则编译

```shell
wget https://ftp.gnu.org/gnu/bison/bison-3.8.2.tar.gz
mkdir build
cd build
../configure  
make -j
sudo make install  # 无sudo权限则指令  ../configure --prefix=$

bison --version
yacc --version
```





### 2.4 libncurse编译

`ncurses`报错则编译

```shell
wget https://ftp.gnu.org/gnu/ncurses/ncurses-6.4.tar.gz
mkdir build
cd build
../configure --prefix=/usr/local/ncurses \
--with-shared \
--with-static \
--enable-overwrite \
CFLAGS="-fPIC" \  
CXXFLAGS="-fPIC"  


./configure --prefix=/usr/local/ncurses --with-shared --with-static --enable-overwrite CFLAGS="-fPIC" CXXFLAGS="-fPIC"  


make -j
sudo make install  # 无sudo权限则指令  ../configure --prefix=$
```
