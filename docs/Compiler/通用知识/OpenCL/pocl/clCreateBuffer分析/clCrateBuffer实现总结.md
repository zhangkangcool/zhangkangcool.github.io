## 2. 关键

### 2.1 PoCL 的设计哲学

**分层清晰**: 核心逻辑与设备实现分离

```shell
用户 API → PoCL 核心 → 设备驱动 → 硬件
  ↑          ↑            ↑          ↑
  通用       通用         特定       特定
```

### 2.2 需要做的事情

**只有两件事**:

1. 分配设备内存 (`alloc_mem_obj`)
2. 释放设备内存 (`free`)

其他一切 (参数验证、引用计数、版本追踪) PoCL 已经做好了！
