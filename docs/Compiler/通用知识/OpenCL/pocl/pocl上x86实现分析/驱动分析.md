## 3. 驱动选择机制

查看 [pthread.c](vscode-file://vscode-app/usr/share/code/resources/app/out/vs/code/electron-browser/workbench/workbench.html) 中的 probe 函数：

```c++
unsigned int
pocl_pthread_probe(struct pocl_device_ops *ops)
{
  int env_count = pocl_device_get_env_count(ops->device_name);

  /* 如果环境变量未指定，pthread 将被优先使用 */
  if(env_count < 0)
    return 1;  // 返回 1 表示找到 1 个设备

  return env_count;
}
```

而 [basic.c](vscode-file://vscode-app/usr/share/code/resources/app/out/vs/code/electron-browser/workbench/workbench.html) 中：

```c++
unsigned int
pocl_basic_probe(struct pocl_device_ops *ops)
{
  int env_count = pocl_device_get_env_count(ops->device_name);

  /* 如果环境变量未指定，pthread 将被优先使用，basic 返回 0 */
  if(env_count < 0)
    return 0;  // basic 主动让位给 pthread

  return env_count;
}
```



## 📝 总结

| 项目             | 值                                                           |
| ---------------- | ------------------------------------------------------------ |
| **实际使用驱动** | `pthread`                                                    |
| **编译启用驱动** | [basic](vscode-file://vscode-app/usr/share/code/resources/app/out/vs/code/electron-browser/workbench/workbench.html) + `pthread` |
| **设备类型**     | CPU (HOST)                                                   |
| **主要代码**     | [pthread](vscode-file://vscode-app/usr/share/code/resources/app/out/vs/code/electron-browser/workbench/workbench.html) |
| **基础代码**     | [basic](vscode-file://vscode-app/usr/share/code/resources/app/out/vs/code/electron-browser/workbench/workbench.html) |
| **设备管理**     | [devices.c](vscode-file://vscode-app/usr/share/code/resources/app/out/vs/code/electron-browser/workbench/workbench.html) |
| **并行方式**     | POSIX 多线程 (pthreads)                                      |
| **支持的 CPU**   | Intel Alderlake (12代酷睿 i5-12400)                          |
| **核心数**       | 12 个计算单元（6P+0E核，12线程）                             |

你的向量加法程序使用的就是这个 **pthread CPU 驱动**，它通过 POSIX 线程在你的 12 核 CPU 上并行执行 OpenCL 内核！
