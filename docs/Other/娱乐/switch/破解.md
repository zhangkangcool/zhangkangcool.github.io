



## 格式化







当然可以，在 macOS 上可以通过 `diskutil` 命令行工具来格式化 U 盘为 exFAT，步骤如下：

---

### 1. 先找到 U 盘的设备名
打开“终端”，输入：
```bash
diskutil list
```
你会看到类似这样的输出，找到你的 U 盘（通常是 `/dev/disk2` 或 `/dev/disk3`，注意不要选错内置硬盘）：
```
/dev/disk0 (internal, physical):
   #:                       TYPE NAME                    SIZE       IDENTIFIER
   0:      GUID_partition_scheme                        *500.3 GB   disk0
   1:                        EFI EFI                     314.6 MB   disk0s1
   2:                 Apple_APFS Container disk1         500.0 GB   disk0s2

/dev/disk2 (external, physical):  # <-- 这是你的 U 盘
   #:                       TYPE NAME                    SIZE       SIZE       IDENTIFIER
   0:     FDisk_partition_scheme                        *119.0 GB   disk2
   1:               Windows_NTFS U盘                      119.0 GB   disk2s1
```

---

### 2. 卸载 U 盘（避免占用）
先卸载 U 盘，注意替换成你的设备名：
```bash
diskutil unmountDisk /dev/disk2
```

---

### 3. 执行格式化命令
下面这条命令会：
- 创建一个新的 GPT 分区表
- 格式化为 exFAT
- 卷标名为 `MYUSB`（你可以改成自己想要的名字）

```bash
错误的格式，diskutil eraseDisk ExFAT MYUSB GPT /dev/disk2(无效)
```

> 如果你想使用 MBR 分区表（更兼容一些老设备），可以把 `GPT` 换成 `MBR`：
> ```bash
> 正确的格式 ： diskutil eraseDisk ExFAT MYUSB MBR /dev/disk2（必须用MBR）
> ```

---

### 4. 完成后重新挂载
格式化完成后，U 盘会自动重新挂载，你也可以手动挂载：
```bash
diskutil mountDisk /dev/disk2
```

---

⚠️ **重要提醒**：
- 命令行操作非常直接，**一旦执行就会立即清空数据**，请务必确认设备名（`/dev/disk2`）是你的 U 盘，而不是内置硬盘。
- 卷标名（如 `MYUSB`）不能包含空格和特殊字符，否则需要用引号包裹。
