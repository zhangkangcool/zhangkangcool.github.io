# 欢迎来到 ken 的个人博客

这里是一个使用 MkDocs + Material 构建的技术博客，主题涵盖编译器、编程语言、工具链、系统设备、网络配置、知识笔记和生活记录。

## 主要目录

- [Compiler](Compiler/)：编译器、LLVM、GCC、工具链和优化相关笔记。
- [Program](Program/)：编程语言、开发工具、Linux 命令、机器学习等开发内容。
- [System](System/)：MacOS、Linux 系统安装和软件安装。
- [Device](Device/)：路由器、串口、U 盘、数字设备和外设。
- [Network](Network/)：VPN、代理、HTTP、域名服务器和安全查询。
- [Knowledge](Knowledge/)：博客搭建、专利、论文、Office、学习资源和虚拟货币。
- [Life](Life/)：理财、抢购等生活类记录。
- [Entertainment](Entertainment/)：游戏、音乐、电视等娱乐内容。

## 快速入口

- [关于本站](about/)：站点内容范围、项目结构、本地预览和写作约定。
- [Compiler](Compiler/)：进入主要技术笔记区。
- [Program](Program/)：查看编程、开发工具和工程实践记录。
- [Knowledge](Knowledge/)：查看博客搭建、专利、论文和学习资源。

## 使用方式

本站使用 `awesome-pages` 管理导航。阅读时可以使用顶部目录或搜索；编辑时请修改 `docs/` 下的 Markdown 源文件，再通过 `mkdocs serve` 本地预览。
