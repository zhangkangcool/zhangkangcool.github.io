<h1 align="center">欢迎来到 ken 的个人博客</h1>

这里是一个使用 MkDocs + Material 构建的技术博客，主题涵盖编译器、编程语言、工具链、以及实用教程和笔记。

快速开始：

- 阅读或编辑文章：`docs/` 目录包含所有 Markdown 源文件。
- 本地预览：安装依赖后运行 `mkdocs serve`，默认在 http://127.0.0.1:8000 可访问。
- 构建站点：运行 `mkdocs build`，生成内容放在 `site/`。

导航提示：仓库使用 `awesome-pages` 插件自动构建导航，建议按主题创建或移动 Markdown 文件以影响站点菜单结构。

欢迎贡献：如有改进建议或新文章，请提交 PR。
