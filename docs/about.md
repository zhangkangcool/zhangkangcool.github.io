如何本地预览/贡献：

1. 克隆仓库并安装依赖：

   ```bash
   git clone https://github.com/zhangkangcool/zhangkangcool.github.io.git
   cd zhangkangcool.github.io
   pip install -r requirements.txt
   ```

2. 本地预览：

   ```bash
   mkdocs serve
   ```

3. 编辑 `docs/` 下的 Markdown 文件，提交 PR 或直接推送到 `main`（仓库配置为在 `main` 推送时自动部署）。

贡献说明：欢迎提交文章改进、排版修正或新增笔记。为保持导航结构一致，请遵循仓库中已有的目录划分（例如 `Compiler/`、`Program/`、`useful/`）。
